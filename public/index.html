The dashboard saves runs to Supabase. In Cloudflare, open this Worker → Settings → Variables and Secrets and add these three as type Secret. Here’s what the running site can see right now:

  • SUPABASE_URL
  • SUPABASE_SERVICE_ROLE_KEY
  • APP_PASSCODE a passcode you make up

Names must match exactly. Then reload this page. The README has the full steps.
